06 — Usage Rules
01
Never round the icon corners
The sharp, square geometry of the Welaab icon is intentional — it signals precision and structure. Rounded corners dilute the scientific identity. iOS will apply its own mask; do not pre-round.
02
Acid is an accent, not a background
#C8FF00 is reserved for single high-impact moments: a CTA, a data highlight, a status indicator. Never fill large surfaces with it. It loses power through overuse.
03
No decorative gradients
Welaab does not use purple-to-pink gradients, aurora blobs, or mesh backgrounds. Depth is created through structure, contrast, and the grid — not atmospheric effects.
04
Mono for data, Syne for UI
DM Mono is strictly for data strings, codes, timestamps, and labels. Never use it for body copy. Syne carries all navigation and interface text.
05
Rules are structural, not decorative
1px borders in #0D0D0D define layout zones. They are functional dividers, not decorative flourishes. Use them to separate information, not to add visual texture.
06
The "W+flask" mark is sacred
The combination of the geometric W and the erlenmeyer flask silhouette is the core of the icon. Neither element should be used in isolation or modified in proportion.
